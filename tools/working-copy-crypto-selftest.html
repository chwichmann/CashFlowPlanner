Working-copy crypto self-test

Exercises wwwroot/js/working-copy-crypto.js — the device-key encryption for the plan working copy in localStorage — in a real browser, because Web Crypto and IndexedDB cannot be reached from the xUnit suite. Serve the repository root over HTTP and open this file.

Threat model. This protects the bytes at rest in the browser profile: a lost laptop, a synced backup, a shared machine. It protects nothing against script running on the origin — this page is itself the proof, since it simply calls the module and gets plaintext back. Do not read any assertion below as an XSS defence.

This page creates and deletes a device key in this origin's IndexedDB. Serve it from the repository root (e.g. python3 -m http.server 8080), not from the app's own origin, so it never touches a real user's key.
